# K230 Linux SDK sources

The build uses the official
[`kendryte/k230_linux_sdk`](https://github.com/kendryte/k230_linux_sdk)
at commit `fc6cc2151d54cb307be47f81815023f7ffb0eae6` from its `dev` branch.
The SDK's `make k230_canmv_defconfig` downloads and verifies Buildroot
`2025.02.1`, applies `buildroot-overlay`, and selects the CanMV profile.
The builder merges `recipe/configs/buildroot.config`, then invokes the
SDK's normal Buildroot build target in `/opt/k230_sdk`.

The SDK selects Linux `6.6.36` from
[`ruyisdk/linux-xuantie-kernel`](https://github.com/ruyisdk/linux-xuantie-kernel)
at commit `7d4e1f444f461dbe3833bd99a4640e7b6c2cd529`, U-Boot `2022.10`,
and OpenSBI `1.4`. Its Linux patches and U-Boot/OpenSBI source overlays
are applied by the SDK's Buildroot package rules.
The kernel is fetched as the GitHub source archive for that fixed commit.
`recipe/patches` provides SHA-256 hashes for the Linux, U-Boot and OpenSBI
archives, and the QEMU configuration requires source hashes.

The Linux amd64 builder uses
`registry.gitlab.com/buildroot.org/buildroot/base:20250218.2110` and the
SDK's Xuantie V3.0.2 toolchain. The toolchain is downloaded from
<https://download.kendryte.com/k230/downloads/dl/gcc/Xuantie-900-gcc-linux-6.6.0-glibc-x86_64-V3.0.2-20250410.tar.gz>
and checked against SHA-256
`2215e1ffe1b9b9277b1f5af2f61102e83973163404f29b04da7097fdafa9e1b7`.
Buildroot retains its package-source and toolchain-header checks.

## Linux and root filesystem

Linux uses the SDK's `k230_defconfig` with `recipe/configs/linux.config`.
The root filesystem provides BusyBox, glibc, initialization scripts and
an empty-password root login on `ttyS0` at 115200 baud. The configuration
uses the instruction set implemented by QEMU's C908 and selects gzip CPIO
output with Buildroot reproducible-build support.

The patch in `recipe/patches/linux` adds `k230-canmv-qemu.dts`, which
includes the vendor's `k230-canmv.dts`. It adjusts the CPU extensions,
2 GiB memory range, PLIC, CLINT and UART clock for QEMU, and disables
unmodeled board peripherals. Buildroot compiles this device tree from the
patched kernel sources. The exported name is `k230-canmv.dtb`.

## Firmware

Buildroot builds U-Boot using `k230_canmv_defconfig` and the SDK overlay,
and exports its ELF for QEMU's firmware loader. OpenSBI uses the SDK's
generic platform with `FW_TEXT_START=0x08000000` and
`FW_JUMP_ADDR=0x08200000`.

`recipe/scripts/post-image.sh` wraps `fw_jump.bin` as an uncompressed
RISC-V Linux uImage with load and entry address `0x08000000`. Direct boot
uses QEMU's bundled OpenSBI; firmware boot enters the SDK U-Boot and then
the packaged OpenSBI image. Release archives and their SHA-256 checksums
are generated by the shared packaging script.
